# 公開(デプロイ)のやり方(初心者向け)

道具をインターネット上に公開して、実際のアドレス(URL)を手に入れるための手順です。ここで紹介する「Vercel(バーセル)」というサービスは無料で使え、むずかしいパソコン操作(黒い画面に文字を打つような作業)は一切なく、すべてマウスのクリックだけで完了します。

## 事前に決めておくこと

**合言葉(アクセスコード)を1つ決めてください。**

これは、noteを買ってくれた人だけがこの道具を使えるようにするための、あなただけの秘密の言葉です。他の人が思いつきにくい言葉にしてください。

- 良い例:`sakura2026yht`、`note-happy-731` など、英数字を混ぜたもの
- 避けたい例:`1234`、`password` など、誰でも思いつく言葉

決めたら、忘れないようにメモしておいてください。この後の手順で使います。

---

## 手順

### 1. Vercelのサイトを開く

ブラウザで次のアドレスを開きます。

```
https://vercel.com/signup
```

### 2. GitHubのアカウントで登録する

画面に並んでいるボタンの中から、「Continue with GitHub」(GitHubで続ける)というボタンを押します。今回のプログラムはすでにGitHubというところに保管されているので、そのアカウントでそのままログインするのが一番簡単です。

普段お使いのGitHubのユーザー名とパスワードを入れて、ログインします。

### 3. 新しいプロジェクトを追加する

ログインできたら、画面のどこかにある「Add New...」というボタンを押し、出てきた選択肢から「Project」を選びます。

### 4. リポジトリ(保管場所)を選ぶ

一覧の中から、今回のプログラムが入っている場所(`yasuyukihiguchi117-tech/-`という名前です)を探し、その横にある「Import」というボタンを押します。

もし一覧に出てこない場合は、「Adjust GitHub App Permissions」のようなリンクがあるので、そこからVercelにこのリポジトリを見る許可を与えてください。

### 5. 設定を1か所だけ変える

「Configure Project」という設定画面が出てきます。ここで1か所だけ変更が必要です。

- 「Root Directory(ルートディレクトリ)」という項目を探し、「Edit」を押して `note-generator` と入力します
  - これは「プログラムがこのフォルダの中に入っていますよ」とVercelに伝えるための設定です

### 6. 合言葉を設定する

同じ画面に「Environment Variables(環境変数)」という項目があります。これは「あなただけの秘密の設定」を入れる場所です。ここに、最初に決めた合言葉を登録します。

- 1つ目の欄(Name/名前)に:`VITE_ACCESS_CODE` と入力します(これは決まった名前なので、そのまま正確に入力してください)
- 2つ目の欄(Value/値)に:あなたが決めた合言葉(例:`sakura2026yht`)を入力します
- 「Add(追加)」のようなボタンを押して確定します

### 7. 公開ボタンを押す

画面の下の方にある、大きな「Deploy(デプロイ)」ボタンを押します。1〜2分ほど待つと、花吹雪のようなアニメーションと一緒に「公開できました」という画面に変わります。

### 8. できあがったアドレス(URL)をメモする

画面の中に、`https://なにか.vercel.app` のようなアドレスが表示されます(クリックすると実際に開いて確認できます)。これが、noteの記事に書く「道具のある場所」です。忘れないようにメモしてください。

---

## noteの記事に書き込む

`note-article.md` の中の、次の2か所を今回の内容に書き換えてください。

- `【ここにデプロイ後のアドレス(URL)を貼る〜】` → 手順8でメモしたアドレス
- `【VITE_ACCESS_CODE に設定した値をここに貼る】` → 手順6で決めた合言葉

書き換えたら、実際にそのアドレスをブラウザで開いて、合言葉が正しく通るか、ご自身で一度テストしてから記事を投稿することをおすすめします。

## 合言葉を変更したくなったら

もし合言葉が広まってしまった場合は、Vercelの管理画面の「Settings」→「Environment Variables」から `VITE_ACCESS_CODE` の値を書き換え、もう一度「Deploy」し直せば、新しい合言葉に切り替わります。
